# 0.5.4 디자인 변경 검증

## 변경

공식 Hinge Health 앱 스크린샷과 삼성 헬스 화면을 참고해 시각적 위계를 정돈했다. 홈의 시작 영역, 준비 단계 표시, 운동 그림, 결과의 두 가지 요약, 날짜별 기록 목록과 아이콘 하단 탐색을 수정했다. 운동 중 큰 배경 패널을 제거했다. 색상만으로 운동 상태를 구분하지 않고 기존 행동 지시를 유지했다.

인증·DB·서버·센서 소스·운동 타이밍은 변경하지 않았다. 모의 신호 표시와 측정 상세 펼치기를 유지했다. 그림은 움직임 측정이나 센서 부착 위치를 나타내지 않는다.

## 실행 결과

- JDK 17, Gradle 8.13, SDK 36, Build Tools 35.0.0.
- `:app:testDebugUnitTest :app:assembleDebug :app:lintDebug -Pkotlin.incremental=false` 성공.
- 테스트 70개, 실패 0, 오류 0, 누락 0.
- Lint 오류 0, 경고 15. 경고는 기존 코드 스타일·플랫폼·의존성 업데이트 안내이며 이번 변경에서 의존성을 업데이트하지 않았다.
- 360×640dp 홈에서 시작 버튼이 첫 화면에 표시된다.
- 기존 411×640dp·글자 2배 화면에서 행동 지시와 중단 버튼이 화면 안에 표시된다.
- 여러 기록 중 오른쪽 손목 기록 선택, 일시정지·재개·재연결, 통증·피로 입력, 측정 상세 펼치기 검사 통과.
- Roborazzi로 실제 Compose 렌더 이미지 20개 생성. 홈·준비·시도·휴식·결과·기록과 짧은 화면의 확대 글자를 육안 확인했다.
- 저장소의 원본 400·600·700 글꼴과 Wrapper JAR을 Git blob SHA로 대조한 뒤 최종 빌드를 다시 실행했다.

현재 작업 환경의 프록시와 테스트 SDK 다운로드는 작업 환경에만 설정했다. 이 설정이나 개인 서버 키는 소스에 포함하지 않았다. 모든 테스트는 모의 계정·기록을 사용했으며 실제 환자 사용성·기기·센서 검증을 뜻하지 않는다.

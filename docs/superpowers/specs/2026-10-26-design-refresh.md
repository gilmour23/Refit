# ReFit 화면 정돈

사용자 요청: 설치된 앱을 삼성 헬스와 Hinge Health의 실제 화면을 참고해 수정한다. 기능은 ReFit에 맞게 유지한다.

## 디자인 근거

- Hinge Health 공식 App Store 스크린샷: https://apps.apple.com/us/app/hinge-health/id1429270372
  - 홈의 운동 시작 영역을 뚜렷하게 구분한다.
  - 운동 중 시범 동작을 주 콘텐츠로 배치한다.
  - 목록은 작은 행과 구분선으로 구성한다.
- 삼성 헬스 공식 화면: https://www.samsung.com/sec/apps/samsung-health/
  - 제목, 주요 값, 보조 설명을 다른 크기로 구분하고 내용을 정렬한다.

두 앱의 사진·영상·상표는 제품 자산으로 복사하지 않는다. 건강 점수·측정 기능도 도입하지 않는다.

## 적용

기존 Kotlin/Compose를 유지한다. 보라색 강조색, Noto Sans KR, 큰 터치 영역을 유지한다. 홈은 운동 그림과 시작 버튼이 있는 한 영역, 기록은 날짜별 한 패널 안의 목록으로 바꾼다. 준비는 단계 표시와 그림, 운동은 행동 지시와 넓은 그림, 결과는 두 가지 요약과 선택 입력으로 구성한다. 하단 탐색에는 아이콘과 선택 표시를 사용한다.

대안으로 전체 색상 변경 또는 기능 재구성을 검토했지만 이번 요청 범위를 넘으므로 적용하지 않는다. 세부 간격·도형은 구현자가 결정한다.

모의 신호 표시, 통증·피로 입력, 측정 상세 펼치기, 재연결·더 쉬기·중단 기능을 유지한다. 그림은 방향 안내이며 실제 움직임·센서 위치를 나타내지 않는다. 인증·서버·데이터 모델·운동 시간은 변경하지 않는다.

## 검증

기존 PatientScreensTest의 실제 Compose 렌더, 클릭 동작, 짧은 화면과 글자 2배의 중단 버튼 접근성을 확인한다. 테스트·Lint·debug 빌드를 실행하고 렌더된 PNG를 육안 확인한다. 실물 기기 테스트와 실제 센서 검증은 별도다.

# 기기 검증 기록

아래는 **아직 실행하지 않은 검증 양식**입니다. 작성본·로그는 Git에서 제외된 `device-evidence/`에 보관합니다. 테스트 계정을 사용하고 개인정보·토큰·원시 환자 신호를 공유 자료에서 제거합니다.

## 실행 정보

| 항목 | 입력 |
| --- | --- |
| 날짜·담당 | 미입력 |
| Git 브랜치·커밋 | 미입력 |
| 앱 버전·빌드 타입 | 미입력 |
| 기기·Android·글자 크기 | 미입력 |
| 소스 | Mock / 실제 센서 모델·펌웨어 |
| 서버 환경 | 환경 이름만; 키·토큰 제외 |
| 설치 방식 | 새 설치 / 동일 서명 업데이트 |

## 확인 항목

결과는 미실행·통과·실패와 실제 관찰로 기록합니다. 안내 구간 수는 움직임 검출 결과가 아닙니다.

현재 기록 조회는 해당 설치의 로컬 데이터 기준입니다. 새 기기나 앱 재설치 후 서버 기록을 내려받아 복구하는 기능은 아직 없습니다.

| 단계 | 기대 동작 | 결과 |
| --- | --- | --- |
| 로그인·재시작 | 같은 설치에서 앱 재시작 후 같은 계정의 로컬 기록 유지, 다른 계정 기록 비노출 | 미실행 |
| 준비 | 좌우·자세·착용 확인, 준비 시간은 운동 시간에서 제외 | 미실행 |
| 음성·큰 글자 | 한국어 출력/사용 불가 표시, 짧은 화면의 주요 조작 | 미실행 |
| 시도·휴식 | 안내와 시간 일치, 휴식 안내 | 미실행 |
| 정지·백그라운드 | 정지 시간·샘플 제외, 복귀 후 상태 유지 | 미실행 |
| 종료·상태 | 중간 종료 확인, 통증·피로가 상세에 유지 | 미실행 |
| 저장·재실행 | 한 번 저장, 재실행 후 기록 조회 | 미실행 |
| 오프라인·재시도 | 로컬 유지, 재연결 후 중복 없이 요약 업로드 | 미실행 |
| 로그아웃·전환 | 즉시 계정 화면 종료, 이전 계정 기록 비노출 | 미실행 |
| 실제 BLE 연결 | 권한 거부·Bluetooth 꺼짐·연결 실패에서 복구 | 미실행; Mock으로 판정 불가 |
| 실제 BLE 수신 | 새 유효 샘플 전 대기, 규격에 맞는 단위·시간·개수 | 미실행; 규격 필요 |
| 실제 BLE 끊김 | 시간·측정 정지, 대기열 제외, 새 샘플로 재개 | 미실행; 실물 필요 |

## 오류 기록

```text
커밋 / 발생 시각 / 소스:
조작 순서:
기대한 동작:
실제 동작:
관련 오류·화면:
재현 여부:
수정 커밋·재검증:
```

Android Studio Logcat에서 `package:com.refit.app` 필터를 적용하고 문제를 재현합니다. 종료된 앱은 해당 시각의 AndroidRuntime 크래시도 확인합니다. 로그만으로 센서 정확성을 판정하지 않습니다.

Windows 파일 저장 예시입니다. SDK 설치 경로가 다르면 SDK Manager의 실제 경로로 바꿉니다. 앱을 먼저 실행합니다. 여러 기기가 연결됐다면 다른 기기를 분리하거나 `-s SERIAL`로 하나를 선택합니다.

```powershell
$refitAdb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $refitAdb devices
New-Item -ItemType Directory -Force device-evidence | Out-Null
$refitProcessId = & $refitAdb shell pidof -s com.refit.app
if ($refitProcessId) {
    & $refitAdb logcat --pid=$refitProcessId -v threadtime > device-evidence/logcat.txt
}
# 기록 중 재현 후 Ctrl+C. 앱 재실행으로 PID가 바뀌면 다시 시작합니다.
```

화면 이동·샘플 수신 등의 구조화된 진단은 센서 연동 단계에서 필요한 항목만 추가합니다. 현재 코드에 없는 진단을 이 양식이 제공하지는 않습니다.

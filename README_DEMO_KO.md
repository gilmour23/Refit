# Re:Fit 웹 시연 · 2026-11-11

홈커밍데이 게임처럼 **운영 노트북에서 서버를 실행하고, HTTPS 주소를 휴대폰에서 여는 방식**입니다. 사진 측정은 노트북이 처리하고 BLE는 휴대폰 브라우저가 센서에 직접 연결합니다. 노트북이 꺼지거나 인터넷이 끊기면 사진 측정과 새 웹 접속이 중단됩니다.

## 운영 노트북에서

1. Windows x64와 64비트 Python 3.12가 필요합니다. ZIP을 전부 한 폴더에 풀어 주세요. 모델은 포함돼 있습니다. Python 설치 시 Python Launcher를 함께 설치하세요.
2. 처음 한 번 `INSTALL_FIRST.cmd`를 실행합니다. Python 패키지와 검증된 Cloudflare 실행 파일을 다운로드하고 모델·글꼴 실행을 검사합니다. 실패하면 안내된 오류를 먼저 해결하세요.
3. `START_DEMO.cmd`를 실행합니다. 서버가 시작되면 `DEMO_JOIN.html`이 열리고, HTTPS 주소·앱 연결키·팀원용 접속 QR이 표시됩니다.
4. 휴대폰을 Wi-Fi에서 LTE/5G로 바꿔 실제로 접속해 보세요. 주소가 표시됐다는 사실만으로 외부 접속이 검증된 것은 아닙니다.
5. 행사 중 실행 창을 닫지 말고 전원과 인터넷을 유지하세요. 덮개도 열어 두세요. 종료는 실행 창에서 Ctrl+C입니다. 다시 시작하면 HTTPS 주소가 바뀝니다.

이 방식은 Cloudflare Quick Tunnel의 임시 주소를 사용하는 시연용입니다. 정식 운영 서비스의 고정 주소나 가용성을 보장하지 않습니다.

## 휴대폰에서

| 기기 | 사진 측정 | BLE 센서 |
|---|---|---|
| 갤럭시 | Chrome에서 같은 주소 열기 | Chrome에서 Bluetooth 권한 허용 |
| 아이폰·아이패드 | Safari/Bluefy에서 사진 업로드 가능 | App Store의 Bluefy에서 같은 HTTPS 주소 열기 |

QR로 열면 연결키가 전달되고, 읽은 직후 주소에서 제거됩니다. QR과 연결키는 팀원에게만 공유하세요. 브라우저가 새로고침되면 키·사진·측정 결과는 메모리에서 사라지므로 QR을 다시 여세요. 저장되는 것은 센서 UUID 설정뿐입니다. Bluefy로 접속 QR이 열리지 않으면 Bluefy 주소창에 접속 주소를 붙여 넣고 연결키를 입력하세요.

## 사진 측정

손등이 위인 사진과 새끼손가락 쪽이 바닥인 옆 사진, 두 장을 선택합니다. 각각 손 전체·손목 아래 약 10cm·기준 카드를 담으세요. 카드/손 윤곽과 관절점을 자동으로 찾으며 모서리를 수동 선택하지 않습니다. JPG/PNG, 갤럭시 모션포토 JPG(MPO), 아이폰 HEIC를 받습니다. 원본 바이트와 EXIF를 서버로 전송합니다. 한 장 20MiB·2400만 화소를 넘으면 제한됩니다.

11개 유효 치수와 보고서가 모두 있어야 등록됩니다. 실패·미측정 값을 예시 값으로 대체하지 않습니다. 경고는 내용을 확인하고 동의해야 등록됩니다. 보고서 이미지를 누르면 크게 열 수 있습니다. 치수 등록은 3D 보조기 제작 완료나 의료적 적합성 검증을 뜻하지 않습니다.

갤럭시 APK도 그대로 쓸 수 있습니다. `DEMO_JOIN.html`에 표시된 HTTPS 주소와 연결키를 APK 측정 서버 설정에 입력하세요.

## 센서 연결과 운동

하드웨어 팀의 **서비스 UUID, 알림 특성 UUID, signed INT16 little-endian 전송 형식**이 필요합니다. 현재 어느 실제 UUID·보정 계수도 임의로 넣지 않았습니다. 다른 형식(문자열/다채널/헤더 등)은 파서를 맞춘 뒤 사용해야 합니다.

센서 전원을 켜고 다른 휴대폰의 연결을 해제한 다음 웹의 센서 연결 버튼으로 실제 기기를 선택하세요. GATT 알림 구독 후에도 수신이 없으면 대기 상태입니다. 2초 이상 최근 데이터가 없거나 연결이 끊기면 값과 그래프를 비웁니다. 0은 실제 0값으로 표시합니다. 신호는 원시 RMS이며 µV나 회복 등급이 아닙니다. 모터/센서 제어 명령은 보내지 않습니다.

운동 안내는 시도 4초·휴식 6초·3회입니다. 화면을 벗어나면 일시정지합니다. 실제 데이터 수신 없이도 안내 타이머는 작동하지만 센서값은 만들지 않습니다. 참가자가 바뀌면 '참가자 데이터 비우기'를 누르세요.

## 키와 사진 보관

연결키와 별도 관리자 키는 처음 설치할 때 노트북의 `.demo-private/credentials.json`에 생성됩니다. 관리자 키는 접속 QR이나 웹 페이지에 배포하지 않습니다. 키 파일과 `DEMO_JOIN.html`을 공개 저장소에 올리지 마세요. 배포 ZIP에는 키가 없습니다.

입력 원본 파일 자동 보관은 꺼져 있습니다. 생성된 측정 보고서·윤곽·치수는 `vision/out/server`에 남고, 서버에서 다시 읽으려면 관리자 키가 필요합니다. 자동 삭제 기한은 없습니다. 시연 후 필요한 결과만 별도로 보관하고 운영자가 이 폴더를 정리하세요. 브라우저의 '데이터 비우기'는 서버 보고서를 삭제하지 않습니다.

## 검증 범위

입력·인증·원시값 파서·오래된 신호·실패 처리에 자동 테스트를 적용했습니다. Windows/Ubuntu의 실제 MediaPipe 기동과 HTTP 실패 응답은 GitHub Actions에서 별도로 검증합니다. 현재 작성 환경은 네이티브 추론 라이브러리에 CPU 정보 접근 제약이 있어, 이곳에서 제공 사진으로 성공한 치수 결과를 얻었다고 주장하지 않습니다.

**실제 아이폰/갤럭시 BLE 연결, 현장 인터넷, 실제 두 사진의 측정 성공·정확성은 아직 실기기 리허설이 필요합니다.** 사진 측정과 센서 수신 둘 다 기기에서 확인되기 전까지 시연 준비 완료로 보지 마세요.
